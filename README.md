# abilympics

障害者技能競技大会（アビリンピック）の「ホームページ」種目において、模範解答として使用されたWebサイトです。

## 概要

- **目的** : アビリンピック競技課題に対応したWebサイトの実装例・参考コードの提示
- **対象ユーザー** : アビリンピック参加者、Webデザイン・コーディング学習者
- **公開URL** : [URLを記述] (※GitHub Pages等で公開している場合はリンクを貼る)

## 主な機能・特徴

- **レスポンシブ対応** : PCおよびスマートフォンそれぞれの画面サイズに最適化
- **アクセシビリティ配慮** : 見やすさ・使いやすさを意識したレイアウト構成
- **直感的なナビゲーション** : 必要な情報へスムーズにアクセスできるメニュー構造

## 使用技術

- **HTML5**
- **CSS3**
- **JavaScript**
